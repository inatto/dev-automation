# ChatGPT — fechar “Too many requests”

Esta extensão observa apenas páginas `https://chatgpt.com/*`. Quando aparece a janela “Too many requests” com o botão “Got it”, ela remove a janela visual clicando nesse botão automaticamente.

Ela não remove nem contorna o limite de requisições do servidor; apenas fecha o aviso visual.

## Instalação no Chrome

1. Abra `chrome://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione esta pasta: `apps/chrome-extensions/chatgpt-too-many-requests`.
5. Recarregue as abas do ChatGPT já abertas.
